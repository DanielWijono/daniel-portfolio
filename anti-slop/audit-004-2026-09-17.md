# Antislop audit 004

Date: 2026-09-17
Mode: AFTER
Scope: `public/index.html`, the canonical page published by `netlify.toml`

Audits 001 to 003 are closed. This pass looks at what those audits did not reach: content substance, heading semantics, copy that survived earlier fixes, and dead code. `experiments/` remains unpublished and outside the delivery gate.

## Design read

Reading this as: senior iOS developer portfolio for recruiters and engineering leaders, in an editorial craft language, dial ENERGY 2 / RHYTHM 2 / MOTION 1. `DESIGN.md` supplies the direction and the page still matches it.

The visual layer is in good shape. Every finding below is about content, semantics, or leftovers, not about decoration.

## Open findings

1. **HIGH: Five of eleven headings are indistinguishable out of context.** `R-32`, `C-4`
   - Reason: a screen-reader heading list is a primary navigation method. The employer sits in a sibling `div`, not in the heading, so the list reads "Senior iOS Developer, Senior iOS Developer, Senior iOS Developer, iOS Developer, iOS Developer" with nothing to tell them apart.
   - Evidence: browser heading dump returned 13 headings; `h3` text repeats "Senior iOS Developer" three times (`public/index.html:186`, `public/index.html:199`, `public/index.html:215`) and "iOS Developer" twice (`public/index.html:229`, `public/index.html:238`). The distinguishing text lives in `.job-org` below each one.
   - Fix direction: put the employer in the heading itself, or make the employer the heading and demote the role.

2. **HIGH: Half the page has no heading structure below `h2`.** `R-32`, `C-4`
   - Reason: audit-003 finding 4 promoted Work and Experience titles to `h3` but did not reach Skills or Education, so the document outline is inconsistent across sections that look parallel on screen.
   - Evidence: `.subhead` elements "Technical" and "Soft skills" are `div` (`public/index.html:258`, `public/index.html:269`); `.edu-org` elements "Binus University" and "iOS Lead Essentials" are `div` (`public/index.html:283`, `public/index.html:287`). Browser inspection confirms zero `h3` inside `#skills` and `#education`.
   - Fix direction: promote these four to `h3` so every section's sub-items appear in the outline, or restructure Education as a definition list.

3. **MEDIUM: Three of six roles contain no evidence of the candidate's own work.** `C-3`, `C-5`
   - Reason: these entries describe what the employer sells, not what Silverius built. A reader scanning for scope of ownership, which `DESIGN.md` names as the audience's goal, learns nothing from half the Experience section.
   - Evidence: Asian Technology Solutions (`public/index.html:226-233`), Jack's Labs (`public/index.html:235-242`), and PT Sola Interactive / OTOMOTO (`public/index.html:244-251`) each carry a role, an org, and a company descriptor, with no bullet list. Browser check confirmed these three `.job` blocks contain no `ul`.
   - Fix direction: add one concrete contribution line each from the CV, or compress all three into a single "Earlier roles" line so the section stops promising evidence it does not deliver. Do not invent bullets.

4. **MEDIUM: The Accenture descriptor repeats the employer's own marketing line.** `R-16`
   - Reason: "helping businesses build their digital core" is Accenture corporate copy, and "digital core" is a buzzword. Audit-003 finding 9 removed this exact pattern from the Quadrant entry but left this instance untouched.
   - Evidence: `public/index.html:217`.
   - Fix direction: replace with a neutral factual descriptor, or remove it (see finding 7 on consistency).

5. **MEDIUM: The soft-skill tag cloud presents unverifiable self-assessment as scannable evidence.** `C-5`, `C-3`
   - Reason: "Critical Thinking, Teamwork, Problem Solving, Agile, Communication, Time Management" cannot be verified, are claimed by every candidate, and carry the same visual weight as the verifiable technical list beside them. The Experience bullets already demonstrate the same traits with proof, for example leading four developers and coordinating sprint delivery, which makes the tag cloud redundant filler on top of unfalsifiable.
   - Evidence: `public/index.html:268-275`.
   - Tier note: this is not scored HIGH because nothing here is fabricated (`R-38` is not breached); it is evidence-free content, which is a craftsmanship failure.
   - Fix direction: remove the soft-skills column and let the Experience bullets carry those traits, or replace it with something verifiable such as languages spoken or the team-lead scope.

6. **MEDIUM: The footer statement repeats an Experience bullet instead of closing the page.** `R-31`, `C-3`
   - Reason: audit-003 finding 5 correctly fixed the metric's scope, but the resulting sentence now duplicates content already on the page and gives the closing display slot no job of its own. A closing statement should leave the reader with a next step or a current-state read, not restate a 2022-2024 bullet at 40px.
   - Evidence: the footer reads "At Quadrant, maintained a 97% crash-free rate." (`public/index.html:296`), against the Experience bullet "Maintained a 97% crash-free rate using Firebase Analytics and stability improvements" (`public/index.html:207`).
   - Fix direction: make the closing line do closing work, stating current focus or what he is looking for, introducing no new claims; or drop the statement block and let the contact row close the page.

7. **LOW: The context-line pattern is applied to the five lesser roles but not the flagship one.** `R-31`, `C-1`
   - Reason: `job-ctx` appears under Quadrant, Accenture, Asian Technology Solutions, Jack's Labs, and PT Sola Interactive, but not under Bank Negara Indonesia, the current role the whole page is built around. The pattern has no stated rule for when it applies.
   - Evidence: `public/index.html:183-194` has no `.job-ctx`; `public/index.html:201`, `:217`, `:231`, `:240`, `:249` all do.
   - Fix direction: apply it consistently, or drop the pattern and fold employer context into the bullets.

8. **LOW: The Skills list contradicts the hero and pads with routine job activities.** `C-1`, `C-3`
   - Reason: the hero names VIPER as part of the technical range, but Skills omits it. Meanwhile Skills lists "SDLC", "Code Review", "Pair Programming", and "Debugging", which every working developer does and which therefore cannot differentiate a senior candidate; they lengthen the list a recruiter has to scan without adding signal.
   - Evidence: hero at `public/index.html:154` versus tags at `public/index.html:259-266`.
   - Fix direction: align the two lists, and cut entries that describe ordinary practice rather than a capability.

9. **LOW: Dead CSS ships on every page load.** `C-1`
   - Reason: tokens and a state selector are declared but never used, which is half-finished code kept alive by nothing.
   - Evidence: `--color-accent-2` (`public/index.html:17`), `--space-3xl` (`public/index.html:25`), and `--text-display` (`public/index.html:28`) each have zero `var()` references. `.work-link[data-pending]` styles a state no element carries, across three rules (`public/index.html:90-92`); no element in the document has a `data-pending` attribute.
   - Fix direction: delete all four.

10. **LOW: The page ships no meta description.** `C-1`
    - Reason: recruiters reach a portfolio through search results and pasted links, and both render an uncontrolled summary without one. The page controls every other part of its first impression.
    - Tier note: this is adjacent to the rule set rather than a direct hit; no `R-XX` covers document metadata. Flagged as a craftsmanship gap.
    - Evidence: `public/index.html:3-7` contains charset, viewport, icon, and title only.
    - Fix direction: add a one-sentence description drawn from the existing hero copy, introducing no new claims.

## Needs owner input, not a fix
